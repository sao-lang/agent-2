## 四、全局不变量

1. **章号只有一套**：0–57，沿用 `PLAN-v11` 基座（卷 11 增补 51 见设计决定 37）；引用第 13 章以后的章节时写章名或新号，不写旧号。
2. **知识点只有一份定义**：`../outline/1X-知识点-*.md`；章表只引用编号，不重复定义内容。
3. **首尾**：每章章首六行元信息（卷 / 知识点 / 本章回答 / 示例目录 / 读完应当能回答 / 可选的本章不负责）、正文后「这一章建立的 N 件事」、末尾「下一章」+ 一行机器导航，细则见 `WRITING-SPEC.md` 第 1.4 节。
4. **主线不出现封装概念**：第 1–11 卷正文不出现 harness 类名、插点、组件封装；这些只在卷 12。
5. **一篇一节**：每个知识点只有一个落点章；跨章只允许"引用 + 一句边界"。
6. **结构只有一个事实源**：卷、章、标题、知识点、状态都在 `book.json`。章首元信息、章内目录、章末导航、`INDEX.md` 由 `gen_book.py` 生成；文件名 = 章号 + 标题（空格与引号去掉，`：，、` 换成 `-`）。改标题必须同时改文件名，`check_nav.py` 会报错。
