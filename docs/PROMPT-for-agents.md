## 4. 改写的边界

### 必须保留（K1–K6，删了就是"剪断前后文"）
- **K1** 每节第一段（总起句 / 本节要回答的问题）
- **K2** 每张表格**引出它的那一句**，以及**表格之后的判据句**（"后两行是判据""只看这一行无法区分"）
- **K3** 对照关系（A 与 B 的差别、为什么这么分）
- **K4** 术语与**加引号说法的首次定义**（`"任务太复杂"`、`"换参数打转"` 这类，第一次出现必须带解释）
- **K5** 成因句（为什么会这样）
- **K6** 每节末尾的收束句（这一节确立了哪条判据）

### 四类锚点禁删（R13–R15）
- 代码块的来源句（"运行 `code/knowledge/chNN_xxx/foo.py`：" 或"下面是示意代码："）
- 输出块的出处（"…`foo.py` 的输出：" 或"它的输出："）
- 并列项的总起句（"由此有三条推论：""两种做法各有代价："）
- 术语/类型的首次定义句

### 可以删
元话语（"这句话决定了…""值得注意的是""本节/下面"）、情绪词与拟人（致命、坑、兜住、接住）、第二人称场景（"你答不上来"）、判断式粗体（粗体只留字段名/数字/命令）、同一结论的重复表述、不服务于本节结论的背景铺垫。

### 绝对不许动
代码块、输出块、表格、H1、`## 这一章建立的 N 件事`、`## 下一章`、`code/` 目录下的任何文件。

- 需要合并小节时**只改标题行**，且**不许顺手合并连续空行**（那会压掉 Python 代码块里的 PEP8 双空行，`trim_verify` 的 fence 哈希立刻不一致）。
- 删句子带走 `第 N 章` / `x.y 节` / `code/` 引用时，**必须在别处补回等义引用**。
