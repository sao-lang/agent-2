# 章节模板

复制下面的骨架，替换方括号内容。

---

```markdown
# 第 [N] 章 [标题]

> **知识点**：[编号与名称]
> **组件**：[组件名，或"无"]
> **读完应当能回答**：[一个具体问题]

## [N].1 [第一个概念的对象或结论]

[直接进入内容。给出定义、结构或数据。]

## [N].2 [机制]

[说明为什么会这样。给出因果，不贴代码。]

## [N].3 [实现]

运行 `code/chXX_名称/stepN_xxx.py`。

[关键代码片段，10–30 行]

[解释这段代码做了什么，以及输出的哪一部分对应本章结论。]

## [N].4 [边界]

以下情况不在此范围内：

- [情况一]：[原因，指向哪一章]
- [情况二]：[原因]

## [N].5 [这一章建立的 N 件事]

1. [结论一]
2. [结论二]

## [N].6 复现

运行 [脚本]，[改动什么]，观察 [什么现象]。

## [N].7 下一章

[一句话衔接下一章要解决的问题。]
```

---

## 检查清单

写完一章，逐项确认：

### 内容

- [ ] 没有虚构场景、人物、对白
- [ ] 每个数字都能由 `code/` 下的脚本跑出，或属于结构事实
- [ ] 没有估算数字未标注
- [ ] 没有评价性形容词（非常、极其、糟糕、关键、核心）
- [ ] 没有感叹号、反问句
- [ ] 「你」的出现次数为 0 或仅在必要处

### 标题

- [ ] 每个标题都是名词短语或结论句
- [ ] 没有比喻、引号强调、emoji
- [ ] 标题能概括该段内容

### 结构

- [ ] 章首三行元信息齐全
- [ ] 五段齐全且顺序正确
- [ ] 知识点编号与 `OUTLINE.md` 一致
- [ ] 章号与文件名一致

### 代码

- [ ] 脚本已实际运行，输出与正文一致
- [ ] 离线可跑，不需要 API Key
- [ ] 估算值已在代码和正文两处标注
- [ ] 计算类脚本使用了固定种子

### 引用

- [ ] 所有 `第 N 章` 引用存在的章节
- [ ] 所有 `code/` 路径存在
- [ ] 跨章小节的引用准确
