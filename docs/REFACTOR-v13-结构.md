## 三、标题规则

**形态**：名词短语，2–6 字为常态，上限 12 个汉字；不带"一、二、三"序号；一章之内句式不齐平。

**禁用四类**：

| 类别 | 反例 | 改法 |
|---|---|---|
| 问句 | 钱花在哪一环 / 慢在哪 / 块大小怎么定 / 什么时候不该加 | 成本构成 / 延迟构成 / 块大小的判据 / 不适用的情形 |
| 评价与褒贬 | 分数不是概率 / 兜底不是失败 / 模型只会说，不会做 / 会怎么坏 | 分数的含义 / 兜底分支 / 工具调用的前提 / 失效模式 |
| 人称与情绪 | 你 / 我们 / 可怕 / 很贵 / 跑飞 | 换成对象名 |
| 元词与比喻 | 副线：… / 这套做法的边界 / 框架的接管范围 / 唯一能做的只有描述 | 治理四字段 / 适用范围 / 绑定接口 / 工具调用的前提 |

**单字泛标题必须带限定**：`边界`→`适用范围`、`代价`→`迁移成本`、`清单`→`交付前检查表`、`对照`→`与手写版的差异`。

**章名**：只改 5 个，理由是不客观或用了修辞。

| 章 | 原名 | 新名 |
|---|---|---|
| 0 | agent 的差别 | Agent 与一次调用的差别 |
| 2 | 模型为什么编，为什么忘 | 不实输出与上下文丢失 |
| 6 | 工具调用：模型只会说，不会做 | 工具调用：声明、请求与回灌 |
| 23 | 反思：为什么自己评自己没用 | 反思：外部裁判与修复粒度 |
| 24 | 状态：循环记住什么 | 状态：循环要记住的字段 |
