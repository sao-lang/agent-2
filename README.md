# Agent 工程化进阶

> 从"能把 Agent 跑起来"，到"能在线上跑住它"。

本书是基础教程（ai-agents-from-zero）的**进阶补充**。基础教程解决的是"怎么做出功能"，本书解决的是"怎么证明功能是对的、怎么让它在异常时不崩、怎么知道它花了多少钱"。

---

## 这本书解决什么问题

基础教程读完后，你大概率会遇到下面这些情况，而且**搜不到答案**：

| 现象 | 你缺的能力 | 对应章节 |
|---|---|---|
| 改了 prompt，不知道变好还是变坏 | 评测 | 第 16、37 章 |
| Agent 报错，不知道错在哪一步 | 可观测 | 第 2 章 |
| 同一个问题问两遍，结果差很多 | 稳定性设计 | 第 3、4 章 |
| 用户关掉页面，任务丢了 | 状态持久化 | 第 9、20 章 |
| RAG 效果差，只会调 `top_k` | 检索工程 | 第 12、13、15 章 |
| 检索回来的东西"有原文但答不出来" | GraphRAG / 意图识别 | 第 14、15 章 |
| 用户说"我上次说的那个方案"它不记得 | 记忆分层 | 第 17、18 章 |
| 担心 Agent 执行 `DROP TABLE` | 护栏 | 第 19、21 章 |
| 一个请求烧掉 5 块钱，不知道贵在哪 | 成本工程 | 第 22 章 |
| 首字 30 秒才出来 | 延迟工程 | 第 23 章 |
| 知识库越加越乱，答案越来越飘 | LLMWiki | 第 24、25 章 |
| 拆了多 Agent，反而更慢更贵更差 | 多 Agent 判据 | 第 26 章 |
| 出故障后只能靠猜 | 复盘方法论 | 第 38 章 |
| 说不清"我这套东西到底工程化到什么程度" | Harness | 第 42 章 |

## 三条铁律

1. **能跑。** 每个代码块都是可以执行的完整代码，不是伪代码。所有示例都随仓库提供，并且经过实际运行验证。
2. **能失败。** 每章都有**失败实验**——故意让它错，观察错误形态。没故意让它失败过的人，不认为自己理解它。
3. **有数字。** 每章结束时，你必须能给出一个数字（召回率、成本、P95 延迟、拦截率）。给不出数字的"优化"都是玄学。

---

## 本书的组织方式（与基础教程的区别）

基础教程按**组件**组织：LangChain 是什么、LangGraph 是什么、MCP 是什么。

本书按**能力演进**组织：先让底座可测量，再让循环可控，再让上下文可信……每一章解决**一个具体的工程问题**，而不解释一个框架概念。

原因很简单：**组件是可以查文档的，能力只能在解决真实问题的过程中长出来。**

所以每章开头都是一个"你会遇到的坏事"，而不是"某个技术是什么"。
