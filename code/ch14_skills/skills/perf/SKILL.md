# 性能排查

## 什么时候用

用户说「接口变慢了」「P99 从 200ms 涨到 2s」「页面卡」时。

**不要用于**：功能开发、代码风格讨论。

## 步骤

1. **先量化**：P50 / P95 / P99 各是多少？基线是多少？
   没有数字就不要往下走
2. **区分「变慢」还是「变多」**
   - 单次耗时上升 → 变慢
   - 请求量上升但单次没变 → 变多（扩容 or 限流，不是优化）
3. **从外到内排查**：网络 → 应用 → 数据库 → 外部依赖
4. **先 profile 再优化**：不要凭直觉改代码
5. **改完用同一套指标复测**：换了指标就等于没测

## 常见错误

- ❌ 没量化就开始优化
- ❌ 把「请求变多」当成「性能问题」
- ❌ 优化完用不同的指标证明变快了
