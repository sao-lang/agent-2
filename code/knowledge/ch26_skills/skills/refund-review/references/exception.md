# 例外情形

## 定制商品

- 消费者定作的商品，签收后不支持无理由退货（政策第七条第一项）。
- 存在质量问题的，按第三章处理，十五日内可退。
- 判定前必须确认商品是否属于"定作"：商品标题或详情页出现"定制""刻字""改尺寸"任一即为定作。

## 预售商品

- 预售商品以"尾款支付完成"为签收前置条件，签收时间仍取物流妥投时间。
- 预售定金不退，尾款按正常退货规则处理。

## 生鲜商品

- 鲜活易腐商品不支持无理由退货。
- 变质、缺斤少两等质量问题，签收后 24 小时内可申请退款，需提供照片。

## 大件商品

- 家具、家电等大件商品的退回运费按责任划分，无理由退货由消费者承担。
- 需要上门取件的，由平台调度，取件时间不计入七日。
