# outline/ 分册目录

这里是大纲的分册。**先读 [docs/OUTLINE.md](../docs/OUTLINE.md)**，那里有「写哪章读哪册」的加载规则和全局不变量。

| 前缀 | 内容 | 典型使用场景 |
|---|---|---|
| `00-` | 定位、主线/副线、七条能力 | 第一次了解这本书，或写卷 0 |
| `1X-知识点-` | 108 条知识点，按 A/B/C/D/E/F/H/G 分 8 册 | 查某条知识点该讲什么 |
| `20-` | 副线封装推导（5.0–5.7） | 写卷 12（52–57）时 |
| `30-` | 卷章总览（58 章总表） | 判断某概念在哪一卷 |
| `vol00`–`vol12` | 每卷的章表（标题/知识点/讲什么/示例） | 写某一卷的正文时 |
| `40-` | 编排架构章节计划（22/23/33/34/35/38/57） | 写编排相关章时 |
| `41-` | 深水区与 LLM Wiki 附录（G1–G6） | 只写 LLM Wiki 附录时 |
| `42-` | 代码落点 | 确定示例该放哪个目录 |
| `44-` | 形态与结构章节计划（47–50） | 写卷 11 前四章时 |
| `45-` | 架构选型章节计划（51） | 写第 51 章时 |
| `50-` | 知识依赖图 | 判断卷与卷的先后 |
| `51-` | 结业项目（P1–P8） | 写项目说明时 |
| `52-` | 38 条设计决定 | 需要引用"为什么这么定"时 |
| `53-` | 附录 A–F 与调研数据 | 查术语表、覆盖矩阵等 |

**纪律**：一次任务只读需要的两三册；不要为了"稳"把全部分册读进来。改结构时先改分册，再改 `OUTLINE.md` 的指针。
