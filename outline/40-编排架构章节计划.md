## 六之二 · 编排架构：章节计划

> **编号**：本节与全书统一用 `PLAN-v11` 号（22、23、33、34、35、38、56），与已写的 13–21 章一致。
>
> **施工细节**（示例目录、代码清单、逐章检查单、施工顺序、不写什么）见 `docs/PLAN-ARCH.md`；本节只记结构与内容边界。
>
> **一句话总图**：`系统 = 拓扑 + N 个 agent`；`agent = 分派 + 主体 + 校验`。名字按"它挂在哪一层"认，不按字面认。

### 层次与名字的对应（写入每章开头的总图）

| 层 | 回答的问题 | 落在这一层的名字 | 章 |
|---|---|---|---|
| 拓扑 | 有几个上下文、控制权归谁、上下文怎么过去 | supervisor-worker、handoff、blackboard、流水线、讨论式 | 33、35、38 |
| 分派 | 这条请求走哪条分支、分支能做什么 | 规则 / 小模型 / 向量路由、Route Skill（分支内容分三种：提示词 / 工作流 / Skill 程序）、兜底 | 13（机制）、22（位置与契约） |
| 主体 | 这一次怎么一步步推进 | 固定工作流（Workflow）、ReAct、Plan-and-Execute（P&E；ReWOO、LLM Compiler 为变体） | 22 |
| 校验 | 谁判对错、重来几次 | 自评、外部裁判（Reflection）、评分器循环（Evaluator-Optimizer）、Reflexion | 22.7、23 |
| 执行 | 一次调用怎么不出事 | 重试、超时、预算、沙箱、审批 | 卷 6（不是架构） |

**三条使用规则**：层间可叠加、层内互斥；同一层内可嵌套（路由树、拓扑节点里再套一个 agent）；层内有变体，变体不新开层（ReWOO 是 P&E 的变体，Reflexion 是"校验 + 记忆"）。

**被排除在正文之外的**：推理策略（CoT / ToT / GoT / LATS）、集成策略（MoA / 投票）、协议（MCP 属 26 章，A2A 属 34 章）、工程约束（重试 / 沙箱 / 预算）。各自在章末边界处一句带过。
