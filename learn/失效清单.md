## 二、替换实验（harness 的唯一验收方式）

> 判据：换掉一个部件，**只应该消失一件事**。任何一次替换导致别的部件报错，就是耦合。

| 换掉 | 应当只有这件事消失 | 我跑过 | 结果 |
|---|---|---|---|
| Reflector → Null | 自我纠错 | | |
| Router → Always | 分流 | | |
| Knowledge → Null | 查资料（退化成纯对话） | | |
| Planner → Implicit | 先计划再执行（退化成 ReAct） | | |
| Supervisor → Handoff | 中心拥有控制权（结论应一致） | | |
